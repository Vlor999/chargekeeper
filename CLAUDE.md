# Jauge

macOS menu bar app (SwiftUI) + root service (`jaugectl daemon`, registered with `SMAppService`) that limits MacBook battery charging. Project generated by XcodeGen (`project.yml`), updates with Sparkle, releases signed and notarized by `.github/workflows/release.yml`.

## Checks

```sh
make check   # charging policy self-test
make         # Release build (Developer ID identity in the keychain)
```

## Rules

- Never print or commit signing material: Developer ID `.p12`, Sparkle private key (login keychain, account `jauge`), Apple app-specific password.
- `site/` (GitHub Pages landing): sample data only.
- Every visible change: local demo (rendered snapshot or local build in `/Applications`) and explicit user validation before commit/release. No release without validation.
- Branches: work on `dev` (or a branch → PR to `dev`). `main` only accepts PRs from `dev`; a merge with a new `VERSION` triggers the release.
- Detailed rules: `.claude/rules/` (`project`, `swift`, `test`, `subagents`).
- Skills: `worktree` (task → PR to `dev`), `mr-review` (PR review), `grill-me` (stress-test a plan).
- Release and secrets: `docs/release.md`.
