# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Report it privately through GitHub's [Report a vulnerability](https://github.com/Vlor999/chargekeeper/security/advisories/new) form, not in a public issue. The root service (`chargekeeperctl daemon`) and its socket (`/var/run/jauge.sock`) are in scope, as are the app and the update path. You should get an acknowledgment within 7 days (indicative).
